# Personal application policy

Use the preferred application for the task when operating this Mac. Do not
silently fall back to a competing app or web service.

- Email, desktop contacts, and non-Apple calendar access: Thunderbird.
- Calendar on this Mac, iPhone, iPad, and Apple Watch: Apple Calendar.
- Browser: Zen. Use another browser only for a compatibility issue or an
  explicit user request.
- Notes and Markdown knowledge: Obsidian.
- Code: VS Code for graphical work and Neovim for terminal work.
- Terminal: cmux.
- Private messaging: Signal.

Account sign-in, sending messages, changing calendar events, and accessing
private app data require the user's explicit instruction and any required UI
authorization. Do not copy browser, mail, notes, or application databases into
this repository. See `docs/personal-application-policy.md` for the complete
cross-device policy.
